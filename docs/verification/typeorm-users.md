# Проверка миграции users на TypeORM

Дата: 2026-11-07. Изменения не закоммичены по просьбе пользователя.

## Требования и реализация

- Users CRUD, registration и login используют TypeORM. Контракты репозиториев сохранены.
- PostgreSQL схема и связи сохранены; `synchronize: false`, инициализация через `db:init`.
- MongoDB удалена из рабочего кода, зависимостей, Docker и тестовой инфраструктуры.
  В lockfile TypeORM может перечислять mongodb как необязательный peer, сам пакет не установлен.
- Access token по умолчанию 5 минут, IP restriction по умолчанию отключён.
- Тесты выполнялись в созданном для проверки временном PostgreSQL, без обращения к рабочей БД.

## RED / GREEN

До изменения TTL выполнен тест `auth.constants.spec.ts`: ожидал минимум 300
секунд, фактическое значение — 10 (FAIL). После изменения дефолта тот же тест
проходит. E2E дополнительно декодирует реальный login access token и проверяет
`exp - iat >= 300`. Checkpoint-коммиты не создавались по прямому указанию пользователя.

## Что проверяют e2e

- Авторизация суперадминистратора, создание, чтение и удаление пользователей.
- Уникальность логина/email, включая одновременные запросы и повторную регистрацию
  после мягкого удаления.
- Совместимость с SQL-строками и bigint ID больше `Number.MAX_SAFE_INTEGER`.
- Поиск без учёта регистра по login/email через OR, сортировка и пустая страница
  с корректным totalCount.
- Регистрация, подтверждение email, повторная отправка письма, login и `/auth/me`.
- Восстановление пароля, refresh token, завершение сессий и истечение токенов.
- Более пяти запросов registration/login без 429 по умолчанию; отдельная старая
  rate-limit suite проверяет ограничение при явном включении.
- Сохранение работы raw SQL комментариев и реакций.

## Ограничения

Существующие исключения `blogs`, `posts`, `comments`, `app` в `test/jest-e2e.json`
не менялись: эти старые suites не входят в указанные 106 тестов. Рабочие SQL
комментарии и реакции покрыты отдельными включёнными suites.

SMTP в тестах заменён mock; фактическая доставка писем и внешний автогрейдер
не проверялись. Деплой и коммиты не выполнялись. Ошибки общего smoke test и
ESLint существовали до миграции и не исправлялись в рамках этой задачи.
